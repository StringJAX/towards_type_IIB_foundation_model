# Notebooks

The notebooks run on Google Colab: sampling on a GPU runtime, evaluation on a CPU runtime. The transformer notebooks
pass the samples between the two through the user's own Google Drive; for the diffusion notebooks, copy the sample
files into `diffusion/samples/` of the CPU runtime (see `diffusion/evaluate.ipynb`).
